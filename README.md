# Farm Drone Management System — Dashboard

A JavaFX dashboard interface for viewing farm conditions, field activity, and drone status. Created for the CS420 Week 8 Lab.

## Dashboard Features

- Farm overview with a field map and drone/equipment markers
- Today's farm statistics
- Soil moisture charts for the last 7 days and last month
- Recent alerts for field conditions and drone issues
- Sidebar navigation for farm management sections

are sample data, not live farm readings. Other sidebar sections are
outside the scope of this dashboard.
